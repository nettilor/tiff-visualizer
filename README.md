# TIFF Visualizer

Fast viewer for ImageJ/Fiji TIFF stacks and hyperstacks. The ImageJ hyperstack
TIFF layout is the native format: dimensions, channel LUTs, display ranges and
slice labels are read from — and written back in — the same structure Fiji
uses, so files round-trip cleanly.

## Building the standalone app

The app ships as a fully self-contained bundle — Python, Qt and all
dependencies included, nothing to install.

- **macOS**: `bash packaging/build_macos.sh` → `dist/TIFF Visualizer.app`.
  Double-click to run (first launch of the unsigned app: right-click → Open
  once, or `xattr -cr "dist/TIFF Visualizer.app"`). Drag to /Applications if
  you like.
- **Windows**: on a Windows machine with Python 3.10+ installed, run
  `packaging\build_windows.bat` from the repo root. It creates its own venv,
  installs everything, and produces `dist\TIFF Visualizer\` — zip that folder
  to distribute; users run the `TIFF Visualizer.exe` inside.
- The flat app icon (stacked z-slices in the channel colors) is generated by
  `packaging/make_icon.py` (icns + ico + in-app png).

### The macOS disk image

`bash packaging/make_dmg.sh` rebuilds the app and packages
`build/TIFF-Visualizer-<version>-macos.dmg`: a drag-to-Applications window
with the first-launch Gatekeeper steps drawn on the background
(`packaging/make_dmg_background.py`). That is the file to attach to a release —
the update check looks for a `.dmg` or a `macos`-named archive.

The app is ad-hoc signed, not notarized (notarizing needs a paid Apple
developer account), so the first launch on any other Mac goes: macOS says it
cannot verify the developer → **Done** (never *Move to Trash*) → System
Settings → Privacy & Security → **Open Anyway**. Once, ever. If a copy was
moved around before that and macOS calls it damaged instead, `xattr -cr
"/Applications/TIFF Visualizer.app"` clears the quarantine flag.

The build is Apple Silicon only — PyInstaller freezes the interpreter it runs
on, so a universal build would need a universal Python and universal wheels
for numpy/imagecodecs/PySide6.

## Updates

The app checks its [releases page](https://github.com/nettilor/tiff-visualizer/releases)
at most once a day and stays quiet unless there is something newer — and never
says a word offline. When an update exists it offers to fetch the download into
your Downloads folder and open it, ready to drag into Applications; nothing is
ever installed behind your back. **Check for Updates…** (in the TIFF Visualizer
menu on macOS, the File menu elsewhere) asks on demand, and **Check for updates
automatically** in Settings turns the daily look off. That check is the only
network request the app ever makes.

For the check to find a build, a release needs a downloadable asset whose name
says which platform it is for — `TIFF-Visualizer-1.3.1-macos.dmg` (what
`packaging/make_dmg.sh` writes) and `TIFF-Visualizer-1.3.1-windows.zip`. A
release with no matching asset still gets offered; the alert then just opens
the release page. Tags must be plain `v1.3.1`-style versions: anything else is
deliberately never offered (`tiff_visualizer/updater.py`).

## Setup

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
```

## Run

```sh
.venv/bin/tiffviz path/to/stack.tif      # or several paths, one window each
.venv/bin/tiffviz                        # no args: file picker
```

## Appearance

Black theme throughout — pure black behind the images, black dividers,
near-black chrome — chosen for microscopy work (`tiff_visualizer/theme.py`).

## Control window — folder swap lists

Drop a **folder** onto the control window and it expands with a section: the
folder's name (📁, ✕ to remove the section) and a checkbox per TIFF inside.
**Checking opens the stack, unchecking closes it** — a fast way to swap
between files. **Open all** / **Close all** under the list do the whole folder
in one batch. Checkboxes track reality (stacks closed elsewhere untick),
multiple folders can be dropped, and long lists scroll.

## Control window

A small always-open command window (like Fiji's main toolbar): Open, Save As,
B&C, Projection, Combine/Split, Shared axes, Fit and 100% as buttons — no
shortcuts needed. Buttons target the **active stack** (the last one clicked),
shown at the bottom. Closing the control window quits the app.

## Stack windows

- Header line above the image shows the current slice's label (the original
  filename stored in the ImageJ metadata), the c/z/t position, and dimensions.
- **c / z / t scroll bars** navigate channels, slices, frames (bars appear only
  for dimensions with more than one level).
- **Mouse wheel** over the image scrolls z (Fiji-style); **Shift+wheel**
  scrolls t, **Alt/Option+wheel** scrolls c; **Cmd+wheel** or **trackpad
  pinch** zooms (centered on the cursor), drag pans.
- **←/→** z (with **Shift** t, with **Alt/Option** c), **↑/↓** t, **, / .**
  channel.
- **Composite** checkbox (status bar) blends all visible channels with their
  LUTs; unchecked shows only the active channel.
- Status bar shows the pixel value under the cursor (all channels in composite).
- **▶ on the z/t bars** plays through the dimension (right-click for 2–30 fps);
  **Space** toggles time playback (the shared bar in shared-axes grids; z for
  stacks with no time axis).
- **Z-projection** checkbox: a live projection over z while scrubbing t.
  It is labeled with the active method (**MIP** for max, then MIN / AVG /
  MED / SUM) — right-click it to switch between Max intensity, Min
  intensity, Average, Median and Sum slices on the fly.
- **Cmd+O** opens more stacks; **Cmd+Shift+O** opens a whole folder of TIFFs.
- **Cmd+C / Cmd+E / Cmd+Shift+E**: copy view to clipboard / export PNG /
  export a t- or z-series as a GIF movie — full resolution, current contrast.
- **Cmd+Alt+M** (Image → Export Stack Montage…): the stack as one contact
  sheet — **t across columns, z down rows** with position labels framing the
  sheet (a single varying axis wraps into a near-square grid instead). Options:
  every-nth t/z, z as rows **or as a max projection**, full/half/quarter
  resolution (with a live output-size estimate), and channels **as displayed**
  (the visible channels, like the view) or **one file per channel**
  (`…_C1.png`, `…_C2.png`, …).
- **Cmd+Alt+S / Cmd+Alt+O / Cmd+Alt+R**: save / open / restore-last session
  (open stacks, positions, contrast, layout — auto-saved on quit).
- **?** shows the keyboard cheatsheet. Adjacent planes are pre-rendered and
  cached, so scrubbing back and forth is instant.
- **Cmd+,** opens Settings: **RAM preloading** with a GB budget (stacks that
  fit are copied into memory in the background so playback never waits on the
  disk; over-budget stacks stay memory-mapped) and **text size** (9–24 pt,
  applied live app-wide — shrink it to give the images more room).

## Combined view — Cmd+G

Hybrid of Fiji's floating windows and napari's single-window layout. **Cmd+G**
(or View → Combine/Split) toggles between the two at any time:

- **Split** (default): every stack floats in its own window, Fiji-style.
- **Combined**: all stacks tile into one workspace window as a resizable grid,
  napari-style. Each tile has one compact top line: stack name, slice
  label/position details, and **⧉** (float just this stack back out) / **✕**
  (close it). Click a tile to make it the active pane — menus, shortcuts and
  the B&C pane all target the active pane, and its name is highlighted. The
  **Grid** selector (bottom right) picks the arrangement: Auto (near-square),
  1–4 columns, or one row.

**Alt+Cmd+G** (View → Combine Selected…) opens a checkbox list of all open
stacks to combine only some of them — checked stacks tile into the grid,
unchecked ones stay (or return to) their own floating windows.

**Rearrange tiles by dragging**: grab any tile's header strip (name/details
line) and drop it on another tile — left half inserts before it, right half
after. The **Sort** selector reorders the whole grid instead: **Name**
(natural order, so XY2 < XY10; joining tiles slot in sorted) or **Brightness**
(one shot: brightest tiles first at the current position — reselect to
re-sort); dragging a tile returns the selector to Manual.

**Solo a tile**: press **Enter** (or double-click a tile's header) and that
tile temporarily fills the workspace — same position, zoom and contrast;
**Esc** (or Enter again) drops it back into the grid exactly where it was.
While soloed, the hidden tiles skip rendering, so scrubbing is as fast as a
single window.

**Flag tiles (triage)**: press **F** on a tile to flag it with an amber ★
(F again unflags). Once anything is flagged, a **★ only** checkbox appears in
the grid controls — check it to see just the flagged tiles. Flags persist in
sessions, and View → Copy Flagged Names puts the flagged stack names on the
clipboard for lab notes.

**Export Grid Montage** (Image menu, Cmd+Shift+M): the grid as one labeled,
figure-ready image — a PNG at the current position, or a GIF over t or z —
at full/half/quarter resolution, honoring each tile's contrast, channels and
MIP state. With ★ only or solo active, the montage exports what you see.

Panes are moved, never rebuilt: position, zoom and contrast survive every
combine/split, and each floating window's position and size are remembered,
so splitting puts every stack back exactly where its window was. Stacks opened
while the workspace is up (files or projections) join the grid; otherwise they
get their own window. Closing the workspace window just splits everything back
out — it never discards stacks.

### MIP all

The **MIP all** checkbox in the grid controls projects every tile over z at
once; right-click it to pick the method for the whole grid (it is labeled
**MIP all** / **AVG all** / … like the per-tile toggle). Tiles joining the
grid adopt it, and individual tiles can still be toggled separately.

### Minimalist mode

The **Minimalist** checkbox is maximal-visualization mode: shared axes on,
every per-tile button and control stripped, only the stack name + info line
above each image, tiles packed edge to edge with hairline dividers. All
navigation happens through the shared bars at the bottom.

### Shared view

The **Shared view** checkbox links pan/zoom across all tiles: zoom into a
region on one stack and every tile shows the same region.

### Per-tile lock

The **🔓** button on a tile locks it out of shared axes: it keeps its position
(and gets its own bars back) while the others scrub — pin a reference
timepoint and compare. Unlocking re-adopts the shared position.

### Shared channels

The **Shared channels** checkbox (next to Shared axes) syncs Composite mode
and per-channel visibility across all tiled stacks: toggle a channel off in
one pane and it goes off everywhere. Stacks with fewer channels ignore the
extra indices; panes joining the grid adopt the current shared state.

### Shared axes — Cmd+Shift+G

In the grid, the **Shared axes** checkbox (bottom left) switches between the
two navigation modes:

- **Independent** (default): every tile keeps its own c/z/t bars.
- **Shared**: per-tile bars disappear (tiles sit closer) and a single set of
  c/z/t bars at the bottom drives all stacks at once — ranges span the largest
  stack, and a stack with no image at the current position (e.g. a z-projection
  when z > 1) shows black with a "no image at this position" header. Mouse
  wheel and arrow keys on any tile drive the shared bars.

## Brightness & Contrast — Cmd+Shift+C

One floating B&C pane shared by all windows. By default it **follows whichever
stack window is active**; the **Pin** button anchors it to the current stack so
it stops following.

On top of that, every pane can have its **own B&C panel fused to its side**:
click the **B&C** button in a pane's header to attach one (click again to
close). The fused panel's **⇄** swaps sides, **✕** closes it, and it
travels with the pane through combine/split. Fused panels and the shared
window control the same ranges and stay in sync. Per channel: LUT-colored selector, visibility toggle (for
composite), histogram of the current plane with a draggable min/max region,
Min/Max spinboxes, **Auto** (Fiji-style 0.35% clip), **Reset** (full range),
and **Apply to all** (this channel's min/max to the same channel of every open
stack). The region and spinboxes are clamped to the image's value bounds
(e.g. 0–255 for 8-bit). **Cmd+Z** undoes contrast changes — slider drags count
as one step, and a single undo reverts a whole Apply to all.
Adjusted ranges are saved into the file's ImageJ display ranges, so Fiji shows
the same contrast.

## Projections — Cmd+Shift+P

Max / Min / Mean / Median / Sum over Z or T with a start/stop range. Results
open as new stacks named `MAX_`/`MIN_`/`AVG_`/`MED_`/`SUM_<name>` (Fiji
convention). Mean and Sum promote to 32-bit float, like Fiji.

## Saving — Cmd+S

Save As writes an ImageJ-format hyperstack TIFF (axes TZCYX, LUTs, display
ranges, composite mode, slice labels) that Fiji opens identically.

## Zoom (View menu)

Cmd+= / Cmd+- zoom, Cmd+1 actual size (1 image px = 1 screen px), Cmd+0 fit.

## Testing

`QT_QPA_PLATFORM=offscreen .venv/bin/python -u tests/regression.py` runs the
full regression suite (35 checks over the whole feature matrix, using
example_stacks/). Run it before releases and after risky changes.

`example_stacks/` is 9 GB of local microscopy data and is not in the repo —
point the suite at your own ImageJ hyperstacks, or drop them in under the same
names.

## Architecture

- `tiff_visualizer/stack_io.py` — loads any TIFF via `tifffile`, normalizes to
  a 5D `(T, Z, C, Y, X)` array (memory-mapped when the file is uncompressed,
  so multi-GB stacks open instantly), LUT/range handling, projections, and
  ImageJ-format saving. Rendering downsamples adaptively when a pane shows
  the image small (and returns to full resolution as you zoom in), keeping
  navigation fast even with ~50 stacks tiled at once.
- `tiff_visualizer/viewer.py` — `StackPane` (one stack's complete view,
  portable between hosts), `StackWindow` (floating host), shared menus,
  projection dialog.
- `tiff_visualizer/workspace.py` — the tiled workspace window, combine/split/
  float logic, and shared-axes mode.
- `tiff_visualizer/control_panel.py` — the always-open control window.
- `tiff_visualizer/bc_panel.py` — the floating, focus-following, pinnable
  Brightness & Contrast pane.
- `tiff_visualizer/updater.py` — the GitHub release check, its download, and
  the policy (version comparison, once-a-day, skipped versions) kept in pure
  functions the regression suite exercises without a network.
- `tiff_visualizer/__main__.py` — CLI entry point.
